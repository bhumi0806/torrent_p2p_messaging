# Design Guide

## Visual direction

The current project is a technical prototype, so the design should stay functional, modern, and minimal rather than overly decorative.

## Recommended visual theme

- Theme: dark mode first
- Primary background: deep slate or charcoal
- Secondary surfaces: slightly lighter panels for cards and chat areas
- Accent color: blue or cyan for action states and active connections
- Text color: near-white for readability
- Borders: subtle muted outlines

## UI principles

- Clear hierarchy for peer lists, messages, and controls
- Minimal visual noise so the networking workflow remains easy to follow
- High contrast for status indicators and errors
- Responsive layout that works on desktop browsers first

## Interaction design

- Primary actions should be obvious and near the main content flow.
- Status messages should be visible for connection, encryption, and transfer states.
- Errors should appear in a compact but readable way without breaking the layout.

## Design constraints

- Keep the interface aligned with the current technical focus.
- Avoid introducing a large UI framework unless the product scope grows significantly.
- Prefer small polished components and consistent spacing.
